# 🚀 تطبيق أخبار الفضاء

تطبيق Android جميل لعرض آخر أخبار الفضاء والاكتشافات العلمية مع نظام تنبيهات ذكي.

## ✨ المميزات

### 📱 واجهة مستخدم جميلة
- تصميم Material Design حديث مع ألوان الفضاء
- تدرجات لونية جميلة تعكس جمال الكون
- رسوم متحركة سلسة وتفاعلات ممتعة
- دعم كامل للغة العربية

### 📰 إدارة الأخبار
- جلب الأخبار من مصادر RSS متعددة
- عرض الأخبار في ثلاث تبويبات: (الكل - غير مقروء - المفضلة)
- إمكانية وضع علامة قراءة وإضافة للمفضلة
- تحديث تلقائي للأخبار بالسحب للأسفل

### 🔔 نظام التنبيهات الذكي
- تنبيهات جميلة عند وصول أخبار جديدة
- تشغيل في الخلفية كل 30 دقيقة
- تنبيهات مع صور ونصوص منسقة
- أصوات واهتزاز مخصص

### 🌐 المشاركة والوصول
- مشاركة الأخبار عبر التطبيقات المختلفة
- فتح الأخبار في المتصفح لقراءة كاملة
- حفظ الأخبار محلياً للقراءة بدون إنترنت

## 🛠️ التقنيات المستخدمة

- **Kotlin** - لغة البرمجة الأساسية
- **Room Database** - قاعدة بيانات محلية
- **MVVM Architecture** - معمارية نظيفة
- **LiveData & ViewModel** - إدارة البيانات
- **WorkManager** - المهام في الخلفية
- **RSS Parser** - تحليل ملفات RSS
- **Glide** - تحميل وعرض الصور
- **Material Design** - تصميم جميل
- **Retrofit** - اتصال بالشبكة
- **Coroutines** - البرمجة غير المتزامنة

## 📊 مصادر الأخبار

التطبيق يجلب الأخبار من مصادر موثوقة:
- Space.com - آخر أخبار الفضاء والاستكشاف
- Science Daily - الأخبار العلمية المتخصصة
- إمكانية إضافة مصادر RSS أخرى بسهولة

## 🚀 التشغيل والتطوير

### متطلبات النظام
- Android Studio Arctic Fox أو أحدث
- Android SDK 24 أو أحدث
- Kotlin 1.9.10

1. استنسخ المشروع
```bash

```

2. افتح المشروع في Android Studio

3. قم بمزامنة Gradle

4. شغل التطبيق على جهاز أو محاكي

## 🎨 التخصيص

يمكنك تخصيص التطبيق بسهولة:

### إضافة مصادر RSS جديدة
في ملف `NewsRepository.kt`:
```kotlin
private val rssUrls = listOf(
    "https://www.space.com/feeds/all",
    "https://www.sciencedaily.com/rss/space_time.xml",
    "رابط مصدر RSS الجديد"
)
```

### تغيير ألوان التطبيق
في ملف `colors.xml`:
```xml
<color name="primary_color">#1A237E</color>
<color name="accent_color">#FF5722</color>
```

### تعديل فترة التحديث
في ملف `NewsWorker.kt`:
```kotlin
val workRequest = PeriodicWorkRequestBuilder<NewsWorker>(
    repeatInterval = 30, // الفترة بالدقائق
    repeatIntervalTimeUnit = TimeUnit.MINUTES
)
```
